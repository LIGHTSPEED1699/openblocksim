# OpenBlockSim

A pure client-side, browser-based block diagram simulator for control systems.

Drag blocks from a library, wire them together, configure parameters, and run simulations. Think "open-source Simulink that runs in your browser."

## Development

```bash
npm install
npm run dev
```

## Testing

```bash
npm test        # unit tests (Vitest)
npm run test:e2e # e2e tests (Playwright)
```
